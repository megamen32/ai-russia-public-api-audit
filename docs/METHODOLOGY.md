# Методология и границы вывода

## Что именно измеряет репозиторий

Скрипты читают анонимно доступные данные `ai-russia.ru`: отрасли, матрицы
«отрасль × функция × задача», сценарии и публично связанные с ними записи
кейсов. Они разделяют три разные сущности:

- **сценарий** — описание потенциального применения;
- **кейс** — запись, которую сам публичный API связал со сценарием;
- **ячейка матрицы** — место сценария в классификации.

Это важно: размер одной страницы API — не размер каталога. Если сервер отдаёт
20 записей и поле `total: 4992`, число 20 не становится «размером базы» от
одного лишь оптимизма наблюдателя.

## Воспроизводимый снимок

`summary_final.json` и `evidence/all_13_publicly_linked_cases.csv` — снимок от
24 августа 2026 года. Для него скрипт обошёл 1 000 ячеек матрицы и зафиксировал
13 уникальных case ID, доступных через текущую публичную модель данных.

Результат говорит о представлении данных публичным API в этот день. Он не
доказывает и не опровергает факт внедрения, качество продукта, размер эффекта,
полноту частной базы или деятельность компаний за пределами этого интерфейса.

## Две итерации

В [archive/v2](../archive/v2/) лежит исправленная версия аудитора и её
[список поправок](../archive/v2/KNOWN_CORRECTIONS_AI_RUSSIA.md). Она устраняет
раннюю ошибку интерпретации пагинации и добавляет офлайн-проверку на сохранённом
образце API. Первый аудитор сохранён в корне как исторический артефакт.

## Вежливость к чужой инфраструктуре

Живой режим делает запросы к публичному сайту, сохраняет ответы локально,
уважает паузу между запросами и повторяет временные ошибки с ограниченной
задержкой. Не используйте его как нагрузочный тест. Офлайн-режим ниже не ходит
в сеть и подходит для проверки логики.

```bash
python3 archive/v2/ai_russia_api_audit_v2.py --fixture archive/v2/api_samples.json --out fixture_report
```

Приложенный исходный PDF-кейсбук не публикуется в репозитории: права на
сторонний документ не были переданы вместе с аудитом. Его наличие не требуется
для офлайн-канарейки.
