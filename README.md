# AI Russia API: полный публичный снимок

> Каталог не становится доказательством внедрения только потому, что у него
> много карточек. Поэтому здесь лежат и счёт, и все ответы, из которых он
> получен.

24 августа 2026 года этот репозиторий полностью обошёл анонимный публичный API
`ai-russia.ru`: все 10 отраслей, 4 992 сценария, 1 000 ячеек матрицы и все
доступные детали связанных кейсов.

| Проверка | Результат |
| --- | ---: |
| Отраслей с полным покрытием | 10 из 10 |
| Сценариев: заявлено / получено | 4 992 / 4 992 |
| Ячеек матрицы | 1 000 |
| Ячеек с `hasCases=true` | 10 |
| Уникальных публично связанных case ID | 13 |
| Деталей кейсов с HTTP 200 | 13 |

Полная сводка: [summary.json](data/2026-08-24-live/summary.json). Покрытие
каждой отрасли: [industry_coverage.csv](data/2026-08-24-live/industry_coverage.csv).

## Данные

В [data/2026-08-24-live](data/2026-08-24-live/) лежит один финальный живой
прогон, без старых fixture и частичных выгрузок:

- `all_scenarios.csv` — все 4 992 сценария;
- `all_cases.csv` и `case_details.jsonl` — 13 доступных связанных кейсов;
- `matrix_cells.csv` — все 1 000 ячеек;
- `raw_api/` — 283 неизменённых ответов сервера, включая все страницы и
  результаты `/api/cases/<id>`;
- `report.md` — сгенерированный отчёт.

## Повторный запуск

```bash
python3 -m pip install -r requirements.txt
python3 audit_script_v2.py --out data/new-live-run --delay 0.75
```

Скрипт ограничивает частоту запросов. Не запускайте несколько копий и не
обходите `429` через прокси: это аудит публичного интерфейса, а не соревнование
в том, кто быстрее утомит сервер.

## Граница вывода

13 — это число case ID, которые публичный API связал со сценариями в момент
снимка. Оно не сертифицирует внедрение, эффект, полноту непубличной базы или
работу компаний за пределами этого API.
