# AI Russia public API audit

Минимальный воспроизводимый набор к посту о «Витрине ИИ-кейсов».

## Что проверяется

Скрипт разделяет две сущности собственной модели сайта:

- **scenario** — описание возможного применения ИИ;
- **case** — вложенная запись в `scenarios[].cases[]`, связанная с компанией.

Он обходит:

- `/api/industries`;
- `/api/industries/<slug>/matrix` для всех 10 отраслей;
- `/api/scenarios` с пагинацией;
- `/api/cases/<cuid>` для обнаруженных ID, когда эндпоинт доступен.

Критическое правило: `len(response.scenarios)` — размер страницы, а `response.total` — полный размер выдачи. Скрипт не принимает первые 20 строк за всю базу.

## Зафиксированный результат на 24 августа 2026 года

- 4992 сценария;
- 1000 ячеек отраслевой матрицы;
- 991 ячейка содержит ровно 5 сценариев;
- 990 ячеек имеют `hasCases=false`, 10 — `true`;
- 13 уникальных публично привязанных case ID: 9 Альфа-Банка и 4 Яндекса;
- восемь отраслей не имеют ни одной ячейки с `hasCases=true`.

`13` означает число кейсов, экспонированных текущим анонимным публичным API и привязанных к сценариям. Это не независимый аудит фактического внедрения или заявленного бизнес-эффекта.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python ai_russia_api_audit.py \
  --out ai_russia_api_dump \
  --page-size 20 \
  --delay 0.8 \
  --retries 10 \
  --verbose
```

Скрипт сохраняет неизменённые ответы в `raw_api/`, а также создаёт CSV, `summary.json` и `report.md`. Для HTTP 429 и временных 5xx добавлен экспоненциальный backoff с поддержкой `Retry-After`.

## Содержимое архива

- `ai_russia_api_audit.py` — аудитор публичного API;
- `summary_final.json` — итоговые проверочные числа;
- `evidence/all_13_publicly_linked_cases.csv` — 13 case ID, компании и родительские сценарии;
- `evidence/*.png` — скриншоты публичных заявлений о верификации и подтверждённом эффекте;
- `POST_1024.md` — готовая подпись, 835 символов с Markdown и переносами.
